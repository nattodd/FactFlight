# ✈️ Fact Flight

**Little practice. Big confidence.**

Fact Flight is a free, browser-based math fact fluency application designed to help elementary school students build speed, accuracy, and confidence through interactive practice.

### Features

- 60-question multiplication fluency quizzes
- Two-minute timed tests and untimed practice
- Voice recognition and keyboard input
- Light and dark modes
- First-try accuracy, corrections, and response-time tracking
- Detailed progress history and identification of frequently missed facts
- Responsive layout for desktop and mobile devices
- Local progress storage with JSON and CSV export

### Try Fact Flight

**[Launch Fact Flight](https://nattodd.github.io/FactFlight/)**

No downloads or accounts required.

For microphone-based practice on iPhone, Safari is recommended.

### Planned Enhancements

- Addition, subtraction, and division practice
- Multiple student profiles

- Expanded progress analytics and personalized review

### Technology

Built using HTML, CSS, and vanilla JavaScript. Hosted for free using GitHub Pages.

### Privacy

Quiz results are stored locally in the user's browser. Fact Flight does not require an account or upload student performance data to a server.
