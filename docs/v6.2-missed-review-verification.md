## Accepted behavior

- Results uses only the reviewed flight. Progress defaults to All activities and allows one activity instead. The selected learner's latest five eligible flights within that scope form the rolling review window.
- Wrong retained answers count even after correction; explicit skips count. Untouched questions and unrecognized speech do not. Undo is respected through the remaining attempts/skips.
- Equivalent facts are deduplicated within each activity, including reversed addition/multiplication and School multiplication. Up to five facts are initially selected, most recent mistakes first. Parents can uncheck facts and select alternatives from the eligible list.
- Two first-try successes in distinct later flights retire a fact from rolling review after its latest mistake/skip. Multiple successes in one flight count once. Leaving the five-flight window does not imply mastery.
- Reviews are untimed and retain the original facts, including Level 5 addition in a mixed set. The existing generator creates fresh answer state and shuffles the selected pool. Tiny pools produce shorter reviews; empty pools offer ordinary practice. Repeat opens review setup again.
- Voice uses the existing ready/start, cancellation and recognition lifecycle. Focus labels each question's activity. Worksheet retains its ordinary equations and input behavior. Review setup uses the persistent bottom actions; checkbox selection does not trigger keyboard fallback.
- Guest can review only the current completed flight, in memory. Progress does not offer rolling Guest review. Other learners' reports cannot launch a review under the current learner; choose that learner on Home first. Previous progress remains separate.

## Data and compatibility

The owner confirmed exporting current learner backups before the format change. Tests use isolated synthetic profiles and copies of legacy data, never the owner's history.

New review sessions use `activity: review`, `schemaVersion: 3`, and versioned review configuration containing the selected facts and source scope. Each new item retains its activity and source level/table selection. The family container and old session formats remain unchanged; there is no migration or rewrite of historical records.

Learner export/import validates the new facts against their original generator scopes and checks that session items match the review configuration. Replay after reload/restore keeps the selected facts. CSV attributes activity, level and selected tables per question. Mixed flights contribute only matching items to each activity report; a flight can therefore appear in several activity totals. Filtered review-flight time is the sum of matching items' active time, while All activities retains full flight elapsed time. Opening a filtered log entry opens the complete original flight.

Backups containing review sessions require this v6.2-compatible reader. v6.1 does not support those new records; reverting after creating review history requires a data-aware recovery plan. Existing v5/v6/v6.1 records remain readable and unchanged.
