## Authorization and compatibility

Owner authorized this local increment on 2026-11-19, on `v6.3-development`. No commits, pushes, deployments or publication. Tests use invented histories in isolated Chrome contexts; no real learner exports are used as fixtures.

The existing learner backup envelope, session schemas, importer, question generator and School Test engine are unchanged by this increment. The focus preference uses a separate per-learner browser key, `fact-flight-focus-v1:<learner-id>`, with version 1 and a boolean. It is not included in learner JSON exports or CSV, and is removed with that learner's other preferences. Importing an existing learner backup does not change its focus setting; a restored learner on another browser starts with focus off. No history migration is needed.

## Implemented behavior

- Local follow-up (2026-11-19): activity trophies and partial-progress labels sit at the bottom of naturally growing tiles. Long activity names wrap within the tile. Synthetic partial/all-mastered histories passed layout assertions at 320, 390 and 1440 pixels in light/dark themes, including all-restricted review controls. The practice-focus and grouped-menus suites passed; the mobile all-mastered screenshot was inspected. Physical iPhone Safari/Chrome retesting remains pending. The owner subsequently authorized committing/pushing this follow-up to v6.3-development for Netlify Branch Deploy testing only. Privacy safeguard tests (10), worktree/identity checks and full Gitleaks worktree/history scans passed before staging. Main and production remain unchanged.

- Current readiness trophies appear beside numbered levels, chosen tables/divisors in the selected through-10/12 range, and School Test tables. Activity trophies mean all facts-readiness choices qualify; timed School Test achievements remain separate. Partially mastered activities show a mastered-choice count and stay open.
- Parent corner offers **Focus on unmastered practice**, off by default, for the active learner. The label names that learner. Guest has a temporary independent setting that resets on reload or learner change.
- Mastered restricted choices retain their trophy, readable striped treatment and nearby explanation: “Mastered — parent focus setting.” Focusable `aria-disabled` controls reject selection and are associated with the explanation. Adjacent buttons let a parent allow review. A selected restricted family can still be deliberately deselected.
- A whole activity is restricted only when every selectable level, both family ranges where applicable, and its School Tests where applicable qualify. The activity-level facts trophy alone does not hide unfinished School Tests. Even an all-mastered activity offers a route to choose one flight for review.
- **Allow this flight for review** is tab-local and tied to the current learner and exact selected scope(s). It is consumed only when a flight starts, never stored in history or preferences, and cleared by Home or a scope change. It does not authorize subsequent Practice Again, Next Level or Next Table/Divisor launches.
- Mixed remembered selections are preserved and name the restricted members. The user can explicitly remove mastered members or allow that mixed flight; the app never silently substitutes a choice.
- Restrictions are checked before menu launches, before the engine's Start action and again immediately before generation, including after voice “ready.” Quick shortcuts, remembered setups, repeat/next routes and older replay routes share these checks. A changed setting never interrupts an already running flight.
- Missed-fact review remains available and explains this exception. It does not earn/revoke scope readiness under the existing rules.
- This is a preference, not a PIN or authentication boundary. The UI says anyone with access to Parent corner can change it. If saving the preference fails, the choice applies in memory for that tab and an explicit warning explains that it will not survive reload.

## Automated checks

`node tests/practice-focus.cjs` uses actual shared readiness calculations and valid synthetic records, not forced mastery flags. At 390- and 1440-pixel widths it checks default-off behavior, trophies, disabled selection, one-flight allowances, repeated/remembered/alternate starts, a setting change during mocked voice readiness, uninterrupted active flights, range separation, explicit mixed selection removal, division choices, the unchanged 60-question/two-minute School preset, reload, learner separation, temporary Guest behavior, missed-fact review with focus on, Next Level/Table restrictions and all-mastered review access. Enabling focus leaves the learner history bytes unchanged. A simulated preference-write failure retains the setting in memory and displays the persistence warning. No browser errors or page overflow were observed.

The all-mastered fixture covers every numbered level, both ranges of all twelve multiplication/division families, and all nine School Test tables. The partial fixture deliberately leaves through-12 multiplication unmastered while table 7 through 10 is mastered; divisor 4 through 12 is independently mastered.
