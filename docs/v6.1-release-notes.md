# Fact Flight v6.1.0 — release notes

Released 2026-11-15 to [GitHub Pages](https://nattodd.github.io/FactFlight/) from main commit `f760615`, with annotated tag `v6.1.0` and a [published GitHub release](https://github.com/nattodd/FactFlight/releases/tag/v6.1.0). Production assets and automated smoke checks passed; the owner confirmed actual production voice works on Windows Chrome and iPhone Chrome/Safari. **Release complete.** Netlify production remains unchanged; rollback requires separate approval.

## Easier practice setup and repeat sessions

- Menus remember each learner’s last-started settings separately for each activity and clearly highlight selections. Unstarted changes do not replace saved choices. The Quick shortcut remains separate, and Guest choices remain temporary.
- Practice Again starts a fresh flight directly with the same complete settings, a new record and fresh timing. Voice still waits for “ready.” Older/reloaded flights without a saved view use Review settings.
- Next Level advances one numbered level while retaining compatible settings, including Free Practice. It stops at Level 5 and is absent for School Test and table-selected flights. Change options remains available.
- Repeated flights use fresh balanced sequences, preferring unused fact families where possible. Small pools may reuse facts; repeat spacing and School Test’s fixed preset are preserved.

## Targeted multiplication

- Choose any combination of multiplication tables 1–10, with other factors 1–10, in Quick, Free, Timed Practice or Custom Test. Existing numbered levels and the original 60-question, two-minute School Test remain available.
- Next Table(s) advances every selected table by one and shows the destination: 2, 5 becomes 3, 6. It is absent when any selected table is 10; it does not wrap or drop a table.
- Selected tables appear in setup, active Focus/Worksheet headings, results, history and exports, and persist through repeat actions and remembered preferences.
- Repeat actions preserve learner ownership, check it again after voice readiness, prevent duplicate launches and leave completed records unchanged.

## Data and compatibility

Existing records are not migrated or rewritten. New targeted flights use session schema version 2 with a table selection instead of a numbered level; numbered-level flights retain schema version 1. Family storage and learner-backup envelope versions remain 1. CSV adds `selected_tables` and leaves numbered level blank for targeted flights.

Backups containing targeted flights require v6.1 to import. Do not assume a v6.0 downgrade can correctly display, replay or restore those records. Export valued learner JSON before an update; preserve the files and browser storage. Preview and production have separate storage: importing preview learners into production is deliberate, never automatic. Guest results and disposable menu preferences are not included in learner backups.
