### Reproduction

Use an external Playwright installation via `NODE_PATH`, set `FF_CHROME_CHANNEL=chrome` and a separate `FF_TEST_OUTPUT` for each suite, then run `node tests/<suite>.cjs` for each row above. Some suites start their own local server. Run the five pure suites with Node; set `FF_TEST_APP_MATH=1` for `question-diversity.cjs`. No real learner files are required. Headless localhost networking required sandbox approval in this environment.
