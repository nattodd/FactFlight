# v6.3 division families and tables through 12

Local increment on `v6.3-development`, 2026-11-18. The owner confirmed a fresh production learner backup and explicitly accepted the compatibility boundary below. No commit, push, deployment or publication is authorized.

## What is implemented

- Multiplication: choose one or more tables 1–12, with other factors 1–10 or 1–12.
- Division: choose one or more divisors 1–12, with answers 1–10 or 1–12. Divisor 4 through 12 contains 4 ÷ 4 through 48 ÷ 4; division is exact and never divides by zero.
- Quick, Free, Timed and Custom Test use the chosen scope. Titles, results and remembered setups show its range.
- Practice Again preserves scope/range. Next Table(s) and Next Divisor(s) advance every selected value by one, retain the range and stop when any selected value is 12; no wrapping or dropped choices.
- Empty selections cannot start. Keyboard focus returns to the selected control after rendering. The existing mobile bottom actions remain in use.
- New-scope facts participate in missed-fact review, export/import, and shared reporting/readiness calculations. The new Progress dashboard and grouped menus are not included here.
- Original School Test remains tables 2–10, 60 questions, two minutes and the existing layout, generator and scoring. Numbered-level pools and the preceding allocation increment are unchanged.

Chosen-family generation balances canonical families and displayed variants in rounds. Multiplication reversals share a family; division keeps operand order. Identity practice is deliberate when choosing table/divisor 1, so numbered-level identity caps do not apply. These choices do not establish cognitive difficulty or age suitability.

## Compatibility contract

The learner export envelope remains `fact-flight-learner-export`, version 1. The local family store remains version 1 under its existing key. There is no migration or rewrite of historical sessions.

| Saved scope | Representation | Reader requirement |
|---|---|---|
| Existing numbered levels | Existing session schema 1 | Existing compatible readers |
| Multiplication choices entirely within 1–10, other factor through 10 | Existing session schema 2, `selection: {type: "tables", tables: [...]}` | v6.1+ |
| New selected multiplication scope or any selected division scope | Session schema 4, `selection: {type: "families", families: [...], range: 10 or 12}` plus activity | v6.3+ |
| Existing missed-fact review | Existing session schema 3 and review payload version 1 | v6.2+ |
| Review containing a new-scope fact | Session schema 3 and review payload version 2; each fact keeps its original selection | v6.3+ |
| Original School Test | Existing original representation | Existing compatible readers |

Examples: chosen table 7 through 10 still saves schema 2. Table 7 through 12, table 11 through 10, and Divide by 4 through either range save schema 4. Advancing from table 10 to 11 creates a new-schema flight but never changes the original table-10 flight.

Imports validate activity, schema, range, selected values, exact arithmetic and canonical keys. Duplicate or out-of-range selections, wrong answers/keys and conflicting level metadata are rejected. Old through-10 selections are never silently interpreted as through 12. Shared reports keep different ranges separate.

**New-scope backups cannot be restored by unmodified v6.2.** The old importer rejects these records, potentially rejecting the whole mixed backup. Keep the pre-upgrade backup. Do not use an older app against a store containing new scopes as a rollback method: older screens/readers were not designed for that data. A rollback requires a separate, data-preserving plan. No export silently drops new flights or relabels them as numbered levels.

The selector, results and Manage learners explain the v6.3 requirement. Exporting preserves the actual question and selection data; CSV retains its existing columns and adds an explicit selected-scope column for operation/range clarity. Disposable preferences remember ranges separately from historical results. Guest remains temporary.
