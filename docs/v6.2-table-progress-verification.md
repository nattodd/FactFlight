## User experience and metric rules

Results & Stats includes Times tables at a glance in All activities and Multiplication. A history-window selector defaults to Recent 5 flights; All flights includes saved and currently available unsaved results. Guest wording explicitly says temporary. A table selector offers 1–10 and any other factors already present in this learner's history (including existing higher-level practice); it does not introduce new practice tables or division reporting. All tables displays tables with encounters in the selected window. Selecting an unpractised table displays zero encounters and no percentage or average.

Eligible flights contain attempted or skipped multiplication facts. Recent uses the same latest-five-eligible-flight window for every table, including mixed reviews and legacy School Test. Other activities and untouched questions are excluded. Each retained question encounter counts once overall, once in each distinct factor's table, and once for square facts. Reversed pairs share one distinct-fact identity. Table totals overlap and must not be added together; no exclusive intended table is inferred from operand order.

First-try correct requires one correct retained submission, no skips and final correct status. Wrong attempts count incorrect submissions; skips count skip actions. The first-try percentage always shows its numerator and encounter denominator. Fewer than ten encounters is labelled Small sample; no mastery or improvement claims are made. Average active time uses only finite, nonnegative recorded question times and shows its sample size. Missing times do not silently become zero.

The visible timing note states that active time is not recall speed and includes microphone preparation, listening, input and retries. iPhone voice adds delay. Comparisons should use similar input methods and practice settings. Existing records do not identify operating system or microphone implementation, so this report cannot remove iOS overhead retrospectively. Timer/scoring behavior is unchanged.
