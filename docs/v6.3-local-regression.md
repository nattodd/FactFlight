## Findings and fixes

1. **Actual UI bug — cross-tab import feedback.** The new readiness/focus storage listener rerendered every visible menu after another tab saved. This could erase the import review's writer-lock error. Refreshes now target only Home, Operations & Facts, practice/setup and Parent corner screens. Import and learner-management forms retain their current inputs/errors. Concurrent import checks pass after the fix; no storage-schema or write-lock behavior changed.
2. **Outdated mobile assertions.** The mobile action suite still expected the older “table” empty-selection wording and no next choice beyond table 10. It now checks the current family wording and advances through 11 and 12, then confirms no Next action beyond 12. This did not require changing application behavior.
3. **Engine test isolation.** The test-only engine fixture previously removed profile scripts as one adjacent string. Added reporting scripts changed that adjacency. It now omits profile scripts individually, preserving the intended separation between engine and public-profile tests. The brand fixture serves the current shared dependencies.
4. **Outdated rename-history navigation.** Rename tests now open Results → Flight log and use the current View flight control. Their data-preservation and learner-name assertions remain intact.

After the application fix, the full import, mobile-action, practice-focus, menu, profile and microphone suites were rerun. All passed. Runtime question diversity was also run explicitly. Initial failures remain recorded in the machine-readable evidence; they are not silently relabelled as successful initial runs.

## Reproduce locally

Use a separately installed Playwright package exposed through `NODE_PATH`, with Chrome installed. Keep raw output outside the repository: stack traces may include machine paths, and screenshots should remain local until reviewed.

```text
node scripts/run-local-regression.cjs <private-output-directory>
node scripts/build-educator-guide.cjs --check
node scripts/build-v6.3-test-backups.cjs <private-output-directory>
node scripts/privacy-check.cjs --worktree
git diff --check
```

The runner uses two test processes, isolated per-suite output folders and a timestamped run folder. It clears test filters and returns a failing exit status for a failed suite or named check. To rerun selected suites, append their names after the output directory. The synthetic backup builder writes only invented exports, never production history.
