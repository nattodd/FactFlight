# v6.1 Choose Tables — local verification

Date: 2026-11-15. Branch: `v6.1-development`, following `dc155f8`.

## Implemented scope

Multiplication offers By level or Choose Tables. Select any nonempty combination of tables 1–10; other factors are 1–10. Empty selection disables Continue. Quick, Free, Timed Practice and Custom Test support the selection in Focus and Worksheet views. Existing five levels and the original School Test (tables 2–10, 60 questions, two minutes) remain available.

Generation uses the existing balanced fact-family source. Equivalent reversed facts share one family; full rounds cover each family before reuse, with existing repeat spacing. Selected tables persist per learner/activity and in the separate Quick shortcut. Guest choices remain temporary. Practice Again preserves the selection and voice readiness; Next Level is absent for table-selected flights. Historical replay retains table selection and asks for view review as before.

Results and history show the selected tables. CSV appends `selected_tables` (semicolon-separated) and leaves the numbered-level field blank for targeted flights.

## Storage compatibility

The owner confirmed there is no history they need to preserve before this storage extension. Checks used synthetic data and isolated browser profiles, not real learner records.

New targeted sessions use `schemaVersion: 2` and `selection: {type: 'tables', tables: [...]}` instead of a numbered `level`. Existing numbered-level sessions retain schema version 1. Family storage and learner-export envelopes remain version 1; existing records are not migrated or rewritten. The import validator accepts mixed older/new sessions and rejects malformed table metadata or inconsistent targeted facts. Synthetic v5 and expanded legacy records remain readable, with their original stored JSON unchanged after new sessions and reload.

Backups containing targeted flights require the v6.1 reader: v6.0 cannot import them. Avoid downgrading a browser origin that contains new targeted history to v6.0; keep a backup and use the matching reader. Branch preview and production origins have separate browser storage. Preferences are disposable and excluded from learner backups.
