## Known limitations and publication boundary

Poor iOS retry reliability remains documented, not fixed by this finalization. Keypad fallback is owner-accepted. Only one tab can save learner changes; export an unsaved flight before closing/reloading. Close older-version tabs before switching to the new release. New review backups require a v6.2-compatible reader; an older-version rollback needs separate approval and a data-preserving plan. Parent restriction is browser-local, not a PIN or OS permission lock. Active time is not recall speed.

The owner accepts current physical usability; further refinements belong to v6.3 and have no defined implementation scope yet. No further user testing is requested solely because documentation was finalized. Explicit authorization is still needed for committing, pushing, main promotion and publication. Keep Netlify production unchanged unless separately authorized.
