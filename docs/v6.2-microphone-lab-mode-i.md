## Behavior

**Release-preparation disposition:** Voice experiments are frozen. The executable lab HTML/script and lab-specific tests are removed from the local release tree for `6.2.0-rc.1`; they remain in Git history through `54c58b1`. The behavior below describes the historical experiment, not a shipping feature.

Mode I copies Mode H's fresh single-phrase recognition, rate-2 Your turn cues, Listening after audiostart, temporary heard text, natural endings and 400 ms cooldown. After the fifth correct answer ends naturally and the cooldown completes, it speaks Done at rate 2. The completion cue has no path to create or start a recognizer.

Next flight and mode selection stay disabled during Done; Cancel remains available. On successful cue completion, Next flight starts another five-answer flight without ready, as in Mode H. Cancellation, backgrounding, parent restriction, synthesis errors and a ten-second cue timeout invalidate completion callbacks. Recovery returns to Start attempt from ready rather than claiming successful completion. Incomplete/mismatched or failed recognition flights do not play Done. Event-only exports identify Mode I and completion-cue request/start/end/failure without storing transcripts or learner data. The microphone restriction is honored.

Mode H and all earlier modes retain their existing behavior. The Fact Flight application files are unchanged against HEAD; the lab does not import quiz code or alter learner history. No Audio Session category workaround was added to the lab: this comparison isolates the final synthesis cue.
