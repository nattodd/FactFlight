## Behavior

- A shared validator checks menu launch and remembered configurations.
- Last actually started mode, level, question count, duration, input, view, goal and School table are remembered per learner/activity. Selecting the same mode preserves count and duration; switching modes applies compatible defaults and clears out-of-range goals.
- Mode tiles and School Test show explicit selection and `aria-pressed`. Selected checkmarks are anchored to their buttons.
- Back within setup preserves drafts. Returning Home discards unstarted drafts; changing learners resets them. Voice choices are saved only after ready starts the flight, not on microphone cancellation.
- Existing Quick shortcut preferences remain separate; a valid old Quick preference seeds its activity when no general preference exists.
- New disposable keys are `fact-flight-practice-v1:<learnerId>:<activity>`. Guest uses memory only, cleared on reload/change. Bad values fall back to defaults; failed writes retain temporary choices and show a warning. Learner deletion clears its preference keys.
- No history/profile/backup schema change or migration. No saved user data was accessed or modified. Preferences are not part of learner backups. The original School generator, speech engine, scoring and history adapters remain unchanged.
