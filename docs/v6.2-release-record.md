## Data and rollback boundaries

No stored learner data is deleted, migrated or uploaded by publication. Retain learner JSON backups outside browser storage; CSV is not a restore backup. Close older-version tabs before opening the new release. Only one tab saves; export unsaved flights before reloading and use the saving tab to import when needed.

Mixed-review backups require a v6.2-compatible reader. A wholesale rollback to v6.1 or earlier can lose compatibility and requires separate owner approval plus a data-preserving plan. Never reset production history, clear browser storage or overwrite tags to hide a failed deployment. Netlify production remains unchanged.
