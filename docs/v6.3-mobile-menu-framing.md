## Changes

On screens up to 900px wide, navigating between Home, Math, Operations & Facts, mode, practice, ready and review brings the relevant heading/hero into view, with the shared header above the viewport. Back restores keyboard focus to the triggering choice and scrolls it clear of the dock when necessary. The header remains accessible by scrolling up. Selection-only rerenders do not reframe the page.

A minimum page height allows short menus to scroll far enough to move the header out of view. Only the Math group overview has compact tile padding, icons and text, plus a single-row Back bar. Deeper activity/mode/level/input tiles keep their existing CSS dimensions. Original School Test configuration and all saved-record behavior are unchanged. Very short viewports and large text remain scrollable; no content is clipped or fixed-height forced to fit.
