# v6.2a mobile action area — local verification

Date: 2026-11-15. Branch: `v6.2-development`. Status: implemented locally, unreleased; physical-device acceptance pending.

## Scope and behavior

- Setup places Back and Continue/Start in a persistent bottom area on viewports up to 900 pixels wide, with a compact activity, level/table, question-count and timing summary.
- Results place Practice Again (or Review settings) and eligible Next Level/Table actions in the same area. Change options and the other result controls remain in the page.
- Existing button handlers, validation, repeat eligibility and voice-ready lifecycle are retained. Back is moved rather than duplicated, and returns to its original position on desktop.
- Measured bottom padding keeps page content reachable. Safe-area padding accommodates device insets where exposed by the browser.
- Controls return to normal page flow while an input is focused, below 440 pixels of viewport height, during pinch zoom, or when the action area exceeds 40% of the available height. These fallbacks preserve usable content space; the controls are then reached by scrolling.
- No storage schema, speech engine, scoring or timer changes, and no new dependencies. The roadmap release scope and Available/Coming Soon status remain unchanged, so the README roadmap image remains current.
