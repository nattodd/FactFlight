## Steps and expected results

1. **Learners and Guest.** Create Test A and Test B. Complete one short flight as A; B must not show A's results. Rename B and confirm A is unchanged. In Guest, complete a flight: it must not save or offer export. Change learner or reload: Guest results clear. Return to A: A's saved results remain.

2. **Settings and reload.** As A, start multiplication Quick with tables 3 and 9, five questions, Tap or type and Focus. Finish, return Home, navigate back: started choices remain highlighted. Reload/select A: choices and the separate Quick shortcut remain. Change settings but return Home without starting: abandoned choices must not replace saved settings. Start a different activity or non-Quick mode: the multiplication Quick shortcut remains distinct. B has separate choices.

3. **Choose Tables and headings.** Deselect all tables: Continue is disabled. Choose 3 and 9: setup, active heading and results identify Tables 3, 9, not Level 1. Questions must use a selected table with another factor 1–10. Try a single table, mixed tables and all ten tables. Check both Focus and Worksheet. No explicit 11/12 table buttons should appear.

4. **Scoring, correction, skip and undo.** In a five-question Tap or type flight, answer the first question incorrectly, then correctly; answer the second correctly first time; skip the third and finish. Expect two final correct answers, one first-try answer, one wrong attempt and one skip; untouched questions remain unanswered. Review the fact details and Progress. In another flight, try Undo immediately after an answer: it should reverse that input without double scoring. Desktop: type and press Enter; iPhone: use the app keypad, including delete. Check correct/wrong feedback is clear.

5. **Practice Again and Next Tables.** Finish tables 3, 9 and choose Practice Again: it starts directly with the same options, fresh questions/results and a separate saved flight. Next Tables should show and launch 4, 10. No Next Tables action is offered once any selected table is 10; Practice Again and Change options still work. Also check 2→3, 9→10 and mixed 2, 5→3, 6. The new heading and saved preferences match the new selection. Rapid repeated taps must not create duplicate sessions.

6. **Numbered levels and Next Level.** Switch to By level; start Level 1, finish and choose Next Level: Level 2 starts with the same mode/count/input/view/goal. At Level 5, no Next Level action appears. Selecting numbered levels after table practice must restore numbered headings and generate the selected level's facts.

7. **Timed, untimed and navigation.** Try Quick, Free, Timed Practice and Custom Test with selected tables. Quick is untimed; Free continues until Finish. Use ten questions/one minute in Timed Practice and Custom Test; wait for expiry in at least one and confirm it ends once, records the time limit and prevents further answers. Repeat/advance retains the chosen mode/count/time. During a flight, Home asks whether to continue or finish; continuing must not reset time or results. Try an optional first-try goal and confirm it survives repeat/advance.

8. **Real voice and cancellation.** Choose Voice. Allow the browser/OS microphone and speech permissions when prompted; if already granted, record that a fresh prompt was not exercised. Before saying “ready,” timing and scoring must not begin. Say “ready,” then several correct and incorrect answers: recognized values and scores must match. Practice Again and Next Tables must each wait for a new “ready.” Cancel one microphone-ready dialog: no flight is saved and unstarted choices do not replace preferences. Retry and start successfully. Test in Focus and Worksheet.

9. **Reconnection and fallback.** During Voice, allow recognition to disconnect (for example by switching away and returning if the browser stops it). Use Reconnect microphone; continuing answers must work without resetting scores. Record U if no real disconnect/reconnect was exercised. With microphone access denied or unavailable, cancel Voice and start Tap or type successfully; restore permissions afterward. Do not clear browser data to reset permissions.

10. **Original School Test.** After table-selected practice, open School Test and choose table 7. Verify 60 questions, two minutes, and the three-column Worksheet. It must not inherit the multi-table selection or custom timer. Try spoken answers and keyboard/keypad fallback, skip/correction, and Practice Again. No Next Level/Next Tables action should appear. Finish or let time expire and verify scoring/history. Also open School in Focus to confirm navigation and input remain usable.

11. **Progress, reload and historical review.** Review both a numbered-level and selected-table flight. Labels, attempts, wrong values, skips and timing remain sensible. Reload/select the learner: saved records and totals remain. Review an old/reloaded flight: Review settings asks for the view before launch and retains the correct table selection/mode. No immediate Next Level/Next Tables is offered when the original full setup is unavailable. If actual older history exists, confirm it is readable; otherwise mark that manual check U (synthetic legacy checks are automated).

12. **Backup round trip and learner separation.** Using only disposable Test A, save at least one table-selected flight and one numbered-level flight. Export its learner JSON and attempts CSV. CSV should identify selected tables, without a bogus level. Import the JSON again: duplicates must not create extra flights. To exercise a full restore, confirm the JSON is available, delete only Test A, then import it. Compare flight counts, selections, attempts and scores; reload and recheck. Test B must remain intact throughout. Record download/file-picker issues on each browser. Do not test this using a real learner you wish to keep.

13. **Other math activities.** Start a short Tap or type flight in each other activity: addition, subtraction, division, number bonds, doubles, halves and squares. Check a correct answer, result label, and that multiplication table controls do not appear. Finish and return Home without navigation errors.

14. **Layout and orientation.** Test Focus/Worksheet and results in light/dark themes. On iPhone, rotate portrait/landscape during setup and practice; controls, selected-table labels, active question and answer entry must remain reachable. Check scrolling and focus after wrong/correct answers, Skip and Next Tables. Desktop: check keyboard Tab focus and a narrower window. Android/tablets are optional when available; record unavailable devices U, not P.

## Reporting results

Send device/browser versions, P/F/U per numbered check, and any failure's steps, selected tables, mode, input and view. Screenshots help; avoid real learner information. Example: “iPhone Safari: 1–7 P; 8 P except fresh permission prompt U; 9 reconnect U; 10–14 P.” Do not mark unexercised subchecks passed.

This checklist does not authorize a commit, push or production deployment. Release metadata/notes, backup/rollback preparation, hosting confirmation and explicit production approval remain separate gates.
