## Behavior and architecture

- Results use the shared validated configuration captured when a flight starts. Practice Again launches immediately, with a new ID, empty attempts and fresh timing while retaining learner, activity, level, mode, count/duration, view, input and goal.
- Next Level increments exactly one level and starts immediately. It is offered through Level 4, including Free Practice; hidden at Level 5, School Test, incomplete historical configurations, and configurations with a non-level selection discriminator.
- Change options retains explicit setup review. Older/reloaded flights do not store the full view/configuration and use Review settings instead. No new saved history metadata, schema migration or backup format was introduced. Same-tab configuration snapshots remain in a WeakMap.
- The existing Start handler still performs microphone readiness. Preferences are remembered only after ready starts the flight. Repeated clicks cannot launch again while checking/running. Ownership is rechecked at action time and at begin; deleted learners and mismatched owners cannot start a repeat. Guest uses only its current temporary records.
- A small voice-ready guard leaves the microphone disconnected when begin declines a deleted-owner launch, rather than reporting connected afterward. Normal recognition, permission, reconnect and answer parsing paths are retained.
- The shared expanded-math source accepts transient previous fact keys. Its first balanced round prefers unused families; when all facts were used, a different opening is selected if there is more than one fact. Existing coverage, variant balancing and spacing remain intact. Free Practice uses a bounded last-60-fact context; complete disjoint sets are not promised for small pools.
- School still calls the original generator: 60 questions, two minutes, ten factors per round, alternating operand orientation. A repeat-only wrapper swaps the first two questions if the opening matches the preceding flight. Both belong to the first round, preserving spacing and balance without changing the original generator.
- Result actions stack on narrow screens, with 48px minimum button height. Return Home, progress and export remain available.
